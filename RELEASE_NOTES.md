# Release v0.1.0

## Overview

- First official release of **CryptoMAKA Lab**.
- Includes full documentation suite, CI pipeline with markdown linting and PDF generation, comprehensive test coverage (53 tests passed).
- Added LaTeX installation step to CI to enable PDF generation.
- CI badge now visible in the README.

## Highlights

- **Protocol implementations**: Ju‑Park 2023 protocol, ECC/ECDH counterpart, reduced‑round‑trip extension.
- **Security Lab**: Automated attack vectors (replay, tampering, impersonation, etc.).
- **Benchmark Lab**: Reproducible microsecond‑precision benchmarks with statistical metrics.
- **Quantum Threat Analysis**: Conceptual post‑quantum security discussion.
- **Web Dashboard**: React + Vite UI for running experiments, visualizing results, exporting data.

- PDF academic report: `research/figures/academic-report.pdf` (generated by the CI `docs` job).
