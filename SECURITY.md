## Academic & Experimental Research Notice

**CryptoMAKA Lab** is an academic research platform for evaluating cloud-IoT mutual authentication and key agreement protocols. It is designed for educational demonstrations, benchmarks, and threat modeling simulations. 

It is **NOT** intended for production commercial deployment without security review and hardened hardware key storage.

## Reporting a Security Vulnerability

If you discover a security vulnerability or implementation defect:
1. Do **not** open a public issue.
2. Email the maintainer or project supervisor directly with reproducible steps.
3. Vulnerabilities will be evaluated and patched promptly.
